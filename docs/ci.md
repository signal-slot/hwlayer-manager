# Continuous integration

`.github/workflows/ci.yml` (workflow `ci`, job `checks`) runs on every pull request to `main` and every push to `main`, on `ubuntu-latest`, with the committed `Cargo.lock`: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` (which compiles and runs the C programs with the runner's `cc`, and checks the freestanding backend with `nm`), and two builds for `thumbv7em-none-eabihf` (`composition-core`, and the static library without `std` with the `panic-handler` feature, in release). It does not run the vkms tests (they stay ignored; `scripts/vkms-vm-test.sh` boots a kernel in QEMU and is not a CI check), it does not build or run anything on a board, it does not compile the C backend for Arm, and it does not test the minimum Rust version. Hardware milestones are never claimed from it: a green run says the host tests and the bare-metal Rust builds pass, nothing about hardware.
