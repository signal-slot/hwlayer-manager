# Summary of the 2026-11-28 snapshot: what Linux holds of the display pipeline

read-only snapshot of the Verdin iMX95 on the Mallow carrier with the LVDS panel.
Its header says the file is dated 2026-11-28 and the run was on 2026-11-27 (board
clock); this summary uses the tag `observed 2026-11-28` for what the file shows.
`inferred` marks a conclusion drawn from it. Nothing here comes from outside the
snapshot.
