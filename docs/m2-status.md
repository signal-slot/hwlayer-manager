# M2 status: one row per proposed item

Status as of 2026-11-28, integration tip 663432e.

Scope: the items of "7. Proposed M2 items" in [imx95-zephyr-feasibility.md](imx95-zephyr-feasibility.md) (its list is numbered 1 to 6) and the items M2-01 to M2-12 of [open-issues.md](open-issues.md). This page records state only. It adds no measurement.

Tags, as in [platform-capabilities.md](platform-capabilities.md): **observed (date)** is a dated record in this repository of something seen on a board; **read from source** is stated by a pinned source file; **inferred** is concluded from those.

**Hardware: nothing is done on hardware.** The only observed records in the repository are the two read-only Linux-side snapshots of the Verdin iMX95, [observed-2026-11-27.txt](imx95-zephyr/observed-2026-11-27.txt) and [observed-2026-11-28.txt](imx95-zephyr/observed-2026-11-28.txt), both observed 2026-11-27 (the second file name carries the planner's date). They show what Linux holds. They show no M7 run, no scanout, no VSYNC and no latch. The M7 run is recorded as skipped 2026-11-28 ([feasibility, section 8](imx95-zephyr-feasibility.md)), not failed. M2 is open.

States used: not started; host-built; source-studied; skipped on board (with the reason); observed on board (with a date); in progress, not in this tip.
