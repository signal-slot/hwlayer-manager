# Draft: RK3588 VOP2 and Raspberry Pi HVS rows for `platform-capabilities.md`

Written 2026-11-28 (host UTC). This is a proposal for the roadmap step "fold the RK3588 and HVS sessions into `platform-capabilities.md` once caps-doc lands". It does **not** edit [`platform-capabilities.md`](platform-capabilities.md): that file is held by another plan. The sections below use the same shape as the existing per-platform sections there (an `Item | Finding | Basis` table, then a short list of what does not match and what stays open), so a later item can paste them in.

No new hardware claim is made here. Every row restates a claim of a merged doc, with the tag that doc gives it, and links the doc. Tags:

- **observed 2026-11-28** (or 2026-11-27 where the source doc says so): measured on a board. Anything marked "TEST_ONLY" is an atomic `TEST_ONLY` result: no frame was committed or shown.
- **read from source**: read in the named tree, not run. The tree and commit are in the linked doc.
- **inferred**: a conclusion drawn in the linked doc.
- **pending session**: the question waits for a board session that has not landed. The row carries the data that exist today, if any, and the linked doc's own tag for them.

Portability evidence: the board runs behind these rows never count toward M1, M2 or M3.
